---

## 🎨 Fitur & Desain
- **Gaya Desain Neubrutalism**: Border hitam tebal (4-5px), bayangan tajam (*hard offset shadow*), palet warna kontras (Kuning `#FFD93D`, Biru `#4D96FF`, Merah `#FF6B6B`, Hijau `#6BCB77`, Ungu `#9B51E0`), dan tipografi **Space Grotesk** + **Plus Jakarta Sans**.
- **Mode Terang & Gelap**: Beralih tema secara otomatis/manual dengan penyimpanan state di `localStorage`.
- **Interaksi Suara UI**: Fitur toggle efek suara sintetis *Web Audio API* saat mengklik elemen UI.
- **Dynamic Typing Subtitle**: Animasi teks ketik berganti otomatis di Hero Section.
- **Filter Proyek & Skill**: Pengelompokan proyek dan keahlian berbasis tab interaktif.
- **Modal Detail Proyek & Sertifikat**: Fitur pop-up dialog untuk melihat rincian arsitektur proyek dan sertifikasi.
- **Formulir Kontak & WhatsApp**: Formulir kirim pesan interaktif, salin email instan, dan tombol lansung ke WhatsApp.

---

## 🛠️ Teknologi yang Digunakan
- **Core**: React 19, Vite, TypeScript
- **Styling**: Tailwind CSS v4, Custom Neubrutalism Design Tokens
- **Animasi**: Framer Motion, Canvas Confetti
- **Ikon**: Lucide Icons, Custom SVG Brand Icons

## 🚀 Jalankan Secara Lokal

```bash
# 1. Clone repositori
git clone https://github.com/wokkk15/porto.git
cd porto

# 2. Install dependensi
npm install

# 3. Jalankan server pengembangan
npm run dev
```

Buka `http://localhost:5173/` di browser Anda.
